# 花开给你 · Birthday Garden

手机生日小花园：首页与 `garden/` 均可打开。四朵花藏着祝福，最后是寿星照片。原 `letter/` 花信页面已移除，旧链接跳转到小花园。

## 本地预览

在本目录运行 `python3 -m http.server 8765`，打开 http://localhost:8765 。无需安装依赖或构建。

## 发布

GitHub Pages → Deploy from a branch → main / (root)。资源均使用相对路径，支持项目子路径。

## 内容与图片

祝福文案在 HTML 和 app.js 中。网页中的花艺图片均为全新生成的水彩插画，仅参考花朵品种和配色，不直接使用参考花照。人物照片经过尺寸优化，未经过 AI 修改；WebP 不含原始 EXIF。首页四枝花为透明背景水彩插画，与祝福纸笺统一绘本手绘风格。无统计、无外部请求。背景音乐为用户提供的 T-ara《TIAMO》，低音量循环播放，带暂停开关；浏览器拦截自动播放时，在首次交互后播放。

公开 Pages 及本仓库内图片可被任何人访问。noindex 和 robots.txt 仅提示搜索引擎，不提供访问控制。

页面与祝福纸笺隐藏滚动条，保留触摸、鼠标滚轮与键盘滚动。
